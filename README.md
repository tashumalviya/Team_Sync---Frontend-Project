# TeamSync - Employee Management System (Frontend)

A modern and responsive **Employee Management System Frontend** built with **React.js** and **Vite**. The application provides a clean and user-friendly interface for managing employees, departments, attendance, tasks, and authentication.

> **Note:** This repository mainly contains the frontend implementation. Backend APIs and full MySQL integration are currently under development.

## Features

-  Login & Registration UI
-  Employee Management
-  Department Management
-  Task Management
-  Attendance Management
-  Chat Module
-  User Profile
-  Settings Module
-  Dark & Light Theme
-  Fully Responsive Design

## Tech Stack

### Frontend
- React.js
- Vite
- Redux Toolkit
- React Router
- Axios
- CSS3

### Backend (In Progress)
- Node.js
- Express.js
- JWT Authentication
- bcrypt.js

### Database
- MySQL

---

## Installation

### Clone Repository

```bash
git clone https://github.com/tashumalviya/Team_Sync---Frontend-Project.git
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
npm install
npm run dev
```

---

## 🗄️ Database

The MySQL database schema is included in:

```text
backend/database/teamsync.sql
```

Import the SQL file into MySQL before running the backend.
